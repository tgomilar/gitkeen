# Keyboard shortcuts

On a Mac, use Command. On Windows and Linux, use Control.

## Anywhere

| Key | Action |
|---|---|
| ? | Open or close Help, with every shortcut. |
| Command with Shift and P | Open the command palette. |
| Command with K | Move to the search box. |
| Command with B | Switch branch. |
| Command with Shift and B | Create a branch at the selected commit. |
| Command with Shift and K | Open the commit panel and start typing a message. |
| Command with R | Read the repository again. |
| Command with Shift and F | Fetch from all remotes. |
| Command with Shift and L | Pull the current branch. |
| Command with Shift and U | Push the current branch. |
| Command with + or − | Make the text larger or smaller. |
| Command with 0 | Return the text to the default size. |
| Control with \` | Open or close the console. |

## In the graph

| Key | Action |
|---|---|
| G | Put the keyboard focus on the graph. |
| Up and Down | Move through the commits. |
| Shift with Up or Down | Extend the selection. |
| Page Up and Page Down | Move by 20 commits. |
| Home and End | Go to the newest or the oldest commit. |
| Enter | Open the menu of the commit under the cursor. |
| Escape | Clear the search, then reduce the selection to one commit. |
| R | Revert the selected commits. Gitkeen asks before it changes anything. |

## In the commit panel and the diff viewer

| Key | Action |
|---|---|
| Command with Enter | Commit, while the message box has the focus. |
| Enter | Open the diff of the selected file. |
| S | Stage or unstage the selected file. In the diff viewer, stage or unstage the selected hunks. |
| Escape | Close the diff viewer. |

## In the console

| Key | Action |
|---|---|
| Tab | Take the suggestion. |
| Up and Down | Bring back an earlier command, or move through the suggestions. |
| Command with L | Clear the console. |

The single keys G, R and S do nothing while you type in a text field, or while
a dialog or an editor is open.
